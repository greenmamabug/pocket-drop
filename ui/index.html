Standard Yoto icons and Yotoicons.com search work without signing in. For personal icons, create a public client in Yoto’s developer dashboard and register http://127.0.0.1:8787/callback as its redirect URL. No client secret is needed.

Getting started

            
    
              
  1. 
                Download directly to your Inbox
                
    
                  Go to , then
                  choose Actions → Download → Full Archive. Save that ZIP directly to your
                  Pocket Drop Inbox Folder. You don’t need to unzip your ZIPs! Pocket
                  Drop handles ZIP and 7z archives for you. Folders can contain audio in subfolders;
                  track-list and card-detail files are optional. Existing MYO track lists are used
                  when complete. Otherwise, playback order uses embedded disc/track tags when
                  complete and unique, then folder and file names in numeric order (2 before 10).
                  Opus audio is converted to AAC automatically when you sync; the original download
                  stays unchanged. Getting AAC directly from MYO Studio avoids re-encoding.
                
    
                
    
                  Use Open Inbox to find the folder. You can set Chrome’s download location
                  to this folder, or choose it when saving a download. Pocket Drop discovers new
                  downloads automatically when automatic library updates are enabled; otherwise,
                  click Refresh. Use Add Files to copy downloads saved elsewhere into the
                  Inbox.

  2. 
                Connect your MYO Pocket
                
    
                  Connect with a USB data cable, then turn on USB storage when prompted on your
                  device. For first connection, the player’s primary volume should be named Y2 MAIN.
                  You can rename it later in Storage.

  3.

Numbered ZIP and 7z archives

            

              Pocket Drop reads numbered audio in audio_files, matches numbered PNG icons in
              images, and uses images/cover_image.png as the card cover in your
              library and on Pocket. card.txt and tracks.txt are ignored. Leading
              zeros are fine: audio file 01 matches 1.png. Larger track icons are resized for the
              player using temporary copies.
            

          

          

            
Manage storage

            

              Choose Remove from Pocket using the icon on its row. Confirm the removal, and
              the original stays in your Inbox. You can add it back any time.
            

            
Remove audio from your computer and library

            

              In Finder, move the original ZIP or extracted folder from your Pocket Drop Inbox
              Folder to the Trash. It will leave your local collection after the next update or when
              you click Refresh. If a copy is still on Pocket, you’ll see it as an On Pocket only
              entry until that copy is removed too. If you keep both a ZIP and an extracted folder,
              remove both copies.
            

            

              This does not remove a copy already on Pocket. Use Remove from Pocket for that.
              Files in the Trash can be recovered until you empty it; emptying the Trash makes the
              computer deletion permanent.
            

            
Not seeing your player?

            

              Try another USB data cable, enable USB storage, then click Refresh. Only the verified
              onboard USB volume is used (Y2 MAIN, or the drive you renamed in this app). Player
              software updates have their own guided flow in Settings → Player software.
            

            
A transfer was interrupted?

            

              Reconnect, refresh, and sync that audio item again. Studio Pocket stages transfers so
              a later sync can finish the update.
